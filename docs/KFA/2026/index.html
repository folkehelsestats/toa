2 Formål og avgrensning

Dette dokumentet gir en reproduserbar oversikt over kommunenes forvaltning av alkoholloven i 2025, basert på undersøkelsen som besvares i 2026. Oppsettet følger hovedtemaene i Tall om alkohol: salgs- og skjenkebevillinger, salgs- og skjenketider, kontroll og overtredelser, inndragninger, nye bevillinger og kommunens alkoholpolitikk. I tillegg er enklere oversikter over andre spørsmål i skjema lagt inn også.

Undersøkelsesdata leses fra SPSS-format (.sav). ID-variabelen kommuneid i SAV-filen får umiddelbart navnet kommunenummer. Kommuneinformasjonsfilen skal ha kommunenummer som ID. I resten av analysen brukes bare navnet kommunenummer.

2.1 Undersøkelsen kommunenes forvaltning av alkoholloven

Data om kommunenes forvaltning av alkoholloven kommer fra spørreskjema som kommunene besvarer. Kommunene plikter etter anmodning å gi opplysninger om kommunens forvaltning, jf. alkoholforskriften § 7-3. Opinion, på vegne av Helsedirektoratet, har gjennomført undersøkelsen.

  kom[, svar := factor(

# Lager sumvariabler:
sum_na <- function(x) {
  resultat <- rowSums(x, na.rm = TRUE)
  resultat[rowSums(!is.na(x)) == 0] <- NA_real_
  resultat
}

                       title, subtitle = NULL,
                       caption = NULL, ylab = "Antall",
                       description = NULL, ylim = NULL,
                       decimals = NULL, ysuffix = NULL) {

  spec <- hd_spec(
    DT,
    x = x,
    y = y,
    n = n
  )

  opts <- hd_opts(
    title = title,
    subtitle = subtitle,
    caption = caption,
    ylab = ylab,
    description = description,
    ylim = ylim,
    decimals = decimals,
    ysuffix = ysuffix
  )

  hd_make(
    spec,
    "ranked_bar",
    opts,
    mode = "dynamic"
  )
}
